# Activate your own affiliate links

Affiliate infrastructure is implemented, but no earning links are active until your own approved URLs are configured. No referral ID, commission rate, account approval or income has been fabricated. Repository visibility does not enrol you in a programme.

## Apply through the official programme

- eBay Partner Network: https://partnernetwork.ebay.com.au/ — relevant to eligible eBay purchases, including refurbished listings. Copy links from its official link generator: https://partnernetwork.ebay.com.au/resources/create-your-affiliate-link . Approval and qualifying-transaction rules apply.
- Amazon AU Associates: https://affiliate-program.amazon.com.au/welcome — obtain approval and generate links using Amazon's tools. Product-price/API access is separate; this site does not scrape Amazon or display live Amazon prices. Review https://affiliate-program.amazon.com.au/help/operating/policies . Add Amazon's required Associate disclosure before activating Amazon links.
- Commission Factory: https://www.commissionfactory.com/affiliates — the network states joining as an affiliate is free. Apply for individual merchants inside your approved account; do not assume every listed retailer participates. Official setup: https://help.commissionfactory.com/how-to-apply-to-commission-factory-as-an-affiliate .
- Reebelo partnership enquiries: https://help.reebelo.com.au/hc/en-au/articles/13574332155161-I-d-like-to-partner-with-Reebelo-who-do-I-contact — an enquiry route, not a verified open affiliate programme or a guarantee of referral payments.

Use the live site and project showcase in your application. Complete identity, tax, payment details and programme terms directly with the provider. Never put these details or API secrets into GitHub issues or this public repository.

## Add an approved link

Copy the complete tracking URL generated by the programme for a retailer destination that appears on this site. In your checkout of this repository run:

```sh
python3 configure_affiliate.py --destination 'THE_ORIGINAL_HTTPS_RETAILER_URL' --affiliate-url 'YOUR_COMPLETE_APPROVED_HTTPS_TRACKING_LINK' --confirm-approved
python3 build_site.py
```

The illustrative strings above are intentionally not working URLs. Substitute your real, approved links. Review the output before committing `affiliates.json` and publishing. Only anchors explicitly marked `data-affiliate` are rewritten. They receive `rel="sponsored"` and a visible Affiliate link label. Share buttons, programme-policy links, community RSS URLs and local personal monitoring links are not affiliate destinations.

`direct_links` maps an exact original URL to its approved URL. Existing `templates` support retailer-approved deep links in the automated scanner and opted-in directory links. Public IDs in tracking URLs are expected; API credentials are not. If a scheme or placeholder is invalid the build fails rather than publishing a fabricated affiliate URL.

Use the provider's reporting dashboard to verify tracking and qualifying commissions. This code cannot validate account ownership, retailer approval or whether a purchase qualifies. Do not earn commissions from restricted personal-use RSS content, rewrite OzBargain referral links, or assume approval for one merchant covers another.

## Sharing the project

`project.html` is an original development showcase with a social preview image, GitHub link, copyable LinkedIn draft and LinkedIn share button. Share that page, then review the draft before posting. `LINKEDIN-POST.md` contains the same draft. No LinkedIn post is sent automatically.

The project page is not a legal clearance. New directory sections use original descriptions and official outbound links, not copied product inventories. Existing main-index images still come from retailer feeds. Review applicable permissions for any public product-data source before expanding commercial reuse.
