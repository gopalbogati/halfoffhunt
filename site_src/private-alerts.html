Personal tech alerts

Follow Amazon AU, laptops, PS5, gaming and PC offers using free community RSS. These are community reports, not direct retailer inventory or verified lowest prices.

Option 1: use your own RSS reader

Download tech feed list

Import this OPML file into a free RSS reader. It contains 15 store feeds plus Computing and Gaming. Look for Amazon AU, JB Hi-Fi, Dell, Lenovo, HP, Mwave, Scorptec, EB Games and more. Feed availability depends on the source; blocked or missing feeds cannot be guaranteed.

Option 2: run the personal watcher on your computer

From a local copy of the repository, with Python 3 installed:

python3 ozwatch.py --loop 900 --serve

Open http://127.0.0.1:8765 on that computer. The dashboard only listens on localhost. Keep the computer awake for scans, and press Control+C to stop. On macOS you can also run bash start-private-tech.command inside the repository.

It matches laptop models, PS5 consoles, gaming accessories, graphics cards, SSDs, RAM and monitors. Tech candidates need at least 3 net community votes; they do not need a 50% discount. Edit tech_watch.json to change rules. The first run establishes a silent baseline; later runs notify new matches. Up to six selected notifications are considered each run.

Phone notifications

The repository supports a separate personal ntfy topic through its NTFY_TOPIC secret. This topic is separate from the public Half Off Hunt channel. On ntfy.sh, an unprotected topic acts as a shared secret, not an authenticated private inbox: use an unpredictable topic and do not send sensitive data. For a fully local option, leave notifications unconfigured and use the localhost dashboard.

Public data and private use

Making a dashboard private does not create permission to access or reuse restricted data. This watcher uses published RSS routes, stops failed requests and never republishes their contents to this website. It does not scrape Amazon product pages, bypass login or bot checks, or provide an Amazon price API.

Amazon’s approved API/Associates route is required before enabling Amazon product-data integration. Review the current Amazon programme policies and OzBargain terms. Public commercial reuse of feed contents has not been enabled.
